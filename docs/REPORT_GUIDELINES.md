# Report Guidelines

## Location

Your report must be a Markdown file at:

```
report/REPORT.md
```

Copy `report/REPORT_TEMPLATE.md` to `report/REPORT.md` and complete every section.

## Required Sections

1. Cover information
2. Objectives
3. Software and hardware environment
4. Code::Blocks installation and configuration
5. Hello Kioto implementation
6. Explanation of C program structure
7. Variables and data types
8. Personalised calculation
9. Testing and troubleshooting
10. GitHub workflow
11. Screenshots
12. Individual reflection
13. Conclusion

## Screenshots

Include genuine screenshots showing:

- Code::Blocks installation / about dialog.
- Your project in Code::Blocks.
- Successful compilation (build log).
- Program execution in the console.
- Your GitHub fork, branch, commits and pull request.

Save screenshots in `report/screenshots/` (create the folder) and reference them in
`report/REPORT.md`, for example:

Reference images using standard Markdown image syntax with the path to your screenshot file.

## Quality

- Write in your own words.
- Explain what you learned, not only what you did.
- A report that is clearly copied from another student will be rejected.
